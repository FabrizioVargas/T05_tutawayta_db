# T05_TUTAWAYTA_DB

## Descripción

Este repositorio contiene el diseño y la documentación de la base de datos del proyecto **Tutawayta**, incluyendo el modelo lógico, recursos de apoyo, imágenes y documentación relacionada con el análisis y desarrollo de la base de datos.
