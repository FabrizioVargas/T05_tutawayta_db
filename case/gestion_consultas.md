# Sistema de Gestión de Inventario, Compras y Ventas

## Descripción del Caso

La Asociación de Pitahaya Tutawayta necesita una forma más organizada y eficiente de registrar, almacenar y consultar la información relacionada con sus productos, clientes, socios, compras, ventas e inventario.

Actualmente, parte de la información se gestiona de forma manual, lo que puede generar errores en los registros, dificultades para controlar el stock disponible y demoras al momento de consultar datos importantes para la toma de decisiones.

Por esta razón, se propone el diseño e implementación de una base de datos relacional que permita centralizar toda la información de la asociación y facilitar la gestión de sus actividades diarias. El sistema permitirá registrar productos, organizar categorías, administrar clientes y socios, controlar compras y ventas, y mantener actualizado el inventario.

Con esta solución, la asociación podrá optimizar sus procesos, reducir errores operativos y contar con información confiable para mejorar su gestión comercial.

---

## Objetivo del Sistema

Diseñar una base de datos relacional que permita gestionar de manera organizada la información principal de la Asociación de Pitahaya Tutawayta, apoyando los procesos de inventario, compras, ventas, clientes, socios y generación de reportes.

---

## Alcance

El sistema contempla los siguientes procesos principales:

| Proceso | Descripción |
|----------|-------------|
| Usuarios y socios | Registrar a los socios o trabajadores de la asociación y asignarles un rol dentro del sistema. |
| Clientes | Almacenar y administrar información personal, datos de contacto y ubicación de los clientes. |
| Productos | Registrar productos con nombre, descripción, categoría, unidad de medida y precio. |
| Inventario | Controlar el stock disponible de cada producto y la fecha de actualización. |
| Compras | Registrar las compras realizadas indicando producto, cantidad, precio, proveedor y socio responsable. |
| Ventas | Registrar ventas a clientes incluyendo fecha, total, vendedor y detalle de productos vendidos. |
| Consultas | Permitir búsquedas de información por producto, cliente, socio, compra, venta o inventario. |
| Reportes | Generar información relevante sobre ventas, compras, productos disponibles y movimientos de inventario. |

---

## Gestión de Consultas

La base de datos permitirá consultar la información de manera rápida, precisa y organizada. Algunas consultas importantes para la asociación son:

- Productos disponibles en inventario.
- Clientes registrados en el sistema.
- Ventas realizadas por fecha o por vendedor.
- Compras realizadas a proveedores.
- Productos con bajo nivel de stock.
- Historial de ventas de un cliente.
- Movimientos de compras, ventas e inventario.

Estas consultas facilitarán el acceso a la información y reducirán la dependencia de registros manuales o documentos físicos.

## Beneficios Esperados

| Beneficio | Impacto para la Asociación |
|------------|---------------------------|
| Mejor control del inventario | Permite conocer los productos disponibles y sus cantidades en tiempo real. |
| Información centralizada | Organiza en un solo sistema los datos de clientes, productos, socios, compras y ventas. |
| Reducción de errores | Disminuye errores en el registro y seguimiento de las operaciones. |
| Mayor eficiencia operativa | Facilita el acceso rápido a la información necesaria para las actividades diarias. |
| Apoyo a la toma de decisiones | Permite analizar información mediante consultas y reportes. |
| Mejor gestión comercial | Contribuye a planificar y controlar las actividades comerciales de manera más eficiente. |

---

## Resultado Esperado

Al implementar esta base de datos, la Asociación de Pitahaya Tutawayta contará con una herramienta que mejorará el control, almacenamiento y consulta de la información relacionada con sus operaciones principales. Esto permitirá una gestión más organizada, confiable y eficiente de los procesos de inventario, compras y ventas, contribuyendo al crecimiento y desarrollo de la asociación.
