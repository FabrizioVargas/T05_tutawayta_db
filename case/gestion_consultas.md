# Sistema de Gestion de Inventario, Compras y Ventas

## Descripcion del caso

La Asociacion de Pitajaya Tutawayta necesita una forma mas ordenada de registrar y consultar la informacion relacionada con sus productos, clientes, socios, compras, ventas e inventario.

Actualmente, cuando estos datos se manejan de manera manual o poco estructurada, pueden aparecer problemas como perdida de informacion, errores al registrar operaciones, dificultad para conocer el stock disponible y demoras al momento de buscar datos importantes para la toma de decisiones.

Por esta razon, se propone una base de datos que centralice la informacion de la asociacion y facilite el control de sus actividades diarias. El sistema permitira registrar productos, organizar categorias, administrar clientes y socios, controlar compras y ventas, y mantener actualizado el inventario.

Con esta solucion, la asociacion podra trabajar de forma mas eficiente, reducir errores y contar con informacion confiable para mejorar su gestion comercial.

## Objetivo del sistema

Disenar una base de datos relacional que permita gestionar de manera ordenada la informacion principal de la Asociacion de Pitajaya Tutawayta, apoyando los procesos de inventario, compras, ventas, clientes, socios y reportes.

## Alcance

El sistema contempla los siguientes procesos principales:

| Proceso | Descripcion |
| --- | --- |
| Usuarios y socios | Registrar a los socios o trabajadores de la asociacion y asignarles un rol, como administrador o vendedor. |
| Clientes | Guardar y administrar datos personales, contacto, direccion y ciudad de los clientes. |
| Productos | Registrar productos con nombre, descripcion, categoria, unidad de medida y precio. |
| Inventario | Controlar el stock disponible de cada producto y la fecha de actualizacion. |
| Compras | Registrar compras realizadas, indicando producto, cantidad, precio, proveedor y socio responsable. |
| Ventas | Registrar ventas a clientes, incluyendo fecha, total, vendedor y detalle de productos vendidos. |
| Consultas | Buscar informacion por producto, cliente, socio, fecha, compra, venta o inventario. |
| Reportes | Generar informacion util sobre ventas, compras, productos disponibles y movimientos de inventario. |

## Gestion de consultas

La base de datos debe permitir consultar la informacion de forma rapida y clara. Algunas consultas importantes para la asociacion son:

- Productos disponibles en inventario.
- Clientes registrados en el sistema.
- Ventas realizadas por fecha o por vendedor.
- Compras realizadas a proveedores.
- Productos con bajo stock.
- Historial de ventas de un cliente.
- Movimiento general de compras, ventas e inventario.

Estas consultas ayudaran a que los socios puedan encontrar informacion sin depender de registros manuales o documentos separados.

## Beneficios esperados

| Beneficio | Impacto para la asociacion |
| --- | --- |
| Mejor control del inventario | Permite conocer que productos estan disponibles y en que cantidad. |
| Informacion organizada | Centraliza los datos de clientes, productos, socios, compras y ventas. |
| Reduccion de errores | Ayuda a disminuir equivocaciones en el registro de ventas, compras y stock. |
| Trabajo mas eficiente | Facilita el acceso rapido a la informacion necesaria para las actividades diarias. |
| Apoyo a la toma de decisiones | Permite revisar reportes sobre productos mas vendidos, inventario, compras y ventas. |
| Mejor gestion comercial | Ayuda a administrar mejor las operaciones y proyectar el crecimiento de forma ordenada. |

## Resultado esperado

Al implementar esta base de datos, la Asociacion de Pitajaya Tutawayta contara con una herramienta que mejore el control de su informacion y facilite el seguimiento de sus operaciones principales. Esto permitira que la gestion diaria sea mas clara, confiable y facil de mantener.
